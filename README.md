# TOEIC Master - 多益 750–900 金色證書核心單字卡

> 🏆 專為攻克多益金色證書設計的智能單字卡 Progressive Web App (PWA)。支援手機離線學習、智能排程複習、學習統計分類下鑽與極致穩定的行動端觸控體驗。

---

## 🌟 版本里程碑：V2.0 正常運作版本

本版本為 **V2.0 穩定里程碑**，整合了完整的行動裝置 PWA 支援與大幅度的人因工程操作體驗優化：

- **PWA 原生 App 體驗**：支援 iOS / Android「加到主畫面」，全螢幕沉浸式開啟，無瀏覽器網址列干擾，支援全功能離線使用（Service Worker 快取）。
- **學習統計分類下鑽**：在統計頁面直接點擊「需要加強」、「定期複習」、「未學習新字」或「已掌握」，即可滑出 iOS 質感的詳細單字清單（含音標、釋義、商務例句、🔊發音與⭐收藏）。
- **正反面嚴格等高設計（杜絕跳動）**：重構底部操作欄為「恆定雙排結構」，翻面按鈕與評分按鈕無縫切換，上一題 / 下一題按鍵永久固定，正反面高度 100% 精確一致，徹底消滅翻面時的畫面跳動感。
- **平滑無縫結算**：完成每日 10 題後，直接在原位切換結算卡片，清楚檢視學習成果與再次複習 / 抽題，告別空白版面。
- **手機手勢滑動**：支援左右水平輕滑切換上一題 / 下一題，防誤觸並杜絕 Safari 橡皮筋整頁彈跳。

## 🛠️ 核心功能

1. **單字卡測驗 (Quiz View)**
   - 200 組多益高頻金色證書商務情境詞彙。
   - 正面：英文單字、音標、詞性標籤、語音朗讀、收藏按鈕。
   - 背面：繁體中文核心釋義、多益商務情境英比例句與中文對照。
   - 三段式評分池：【不熟 (磚紅)】、【再複習 (琥珀)】、【已經會了 (深綠)】。
2. **學習統計 (Stats View)**
   - 整體精熟度百分比與彩色堆疊進度條。
   - 四大單字池長條統計圖，點擊任一項目即可下鑽查看該分類完整單字庫。
3. **收藏清單 (Starred View)**
   - 隨時在卡片右上角點擊星號加入個人生詞本，支援隨時朗讀與獨立複習。
